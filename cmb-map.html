Reference products only

Mollweide images and extrema tables are derived from official public Planck (and, below, Pantheon+) releases. They support orientation and offline overlay work. Favourable or discordant patterns would be interpreted only after a documented null test — not asserted here as completed correlation results.

Primary products

The working baseline is the Planck Public Data Release 3 (PR3) SMICA temperature anisotropy map in HEALPix format. PR4 / NPIPE releases are reserved as cross-checks. Visuals use Galactic coordinates in Mollweide projection. The Planck common intensity mask excludes the Galactic plane and other contaminated regions for extrema reported below.

  • SMICA CMB map (PR3 full-mission IQU): product ID COM_CMB_IQU-smica_2048_R3.00_full — IRSA / LAMBDA FITS download · product preview · ESA Planck Legacy Archive portal (search the same product ID if a deep archive URL changes).
  • Common intensity mask: product ID COM_Mask_CMB-common-Mask-Int_2048_R3.00 — IRSA FITS download · preview.
  • CMB map matrix (all pipelines): IRSA PR3 CMB maps matrix (COMMANDER, NILC, SEVEM, SMICA).

Site images below were generated locally with healpy from the public HEALPix products (not hotlinked). Planck map products are cited as ESA / Planck Collaboration.

Extrema method

Field I_STOKES from COM_CMB_IQU-smica_2048_R3.00_full (native NSIDE 2048, units KCMB). Ud-graded to NSIDE 512. Common intensity mask applied (pixels with mask > 0.5 retained; sky fraction ≈ 77.9%). Mild Gaussian smoothing of FWHM 1° before extrema so the list tracks large-scale spots rather than single noisy pixels. Successive extrema use a 10° exclusion disk. Reported values are ΔT in µK on that smoothed, masked map. Coordinates: Galactic longitude/latitude; ICRS RA/Dec via standard conversion.

Pantheon+ directional distance-modulus residuals

Companion sky product for the same planned overlay program. Source: PantheonPlusSH0ES/DataRelease — file Pantheon+_Data/4_DISTANCES_AND_COVAR/Pantheon+SH0ES.dat (Scolnic et al. 2022; cosmology context Brout et al. 2022).

Residual method

δμ = MU_SH0ES − μflat ΛCDM(zHD; Ωm=0.334, H0=73.04 km s−1 Mpc−1), with μ = 5 log10(dL/Mpc)+25. Ωm from the Pantheon+ flat-ΛCDM constraint (Brout et al. 2022); H0 matches the SH0ES 2022 Cepheid scale used for MU_SH0ES (Riess et al. 2022). Unique-CID inverse-variance averages; zHD≥0.01; Galactic |b|≥15°; HEALPix NSIDE=32 inverse-variance means; Gaussian FWHM=7° smoothing; extrema with 15° exclusion. Diagonal MU errors weight the map only — full covariance is required for cosmological inference.
